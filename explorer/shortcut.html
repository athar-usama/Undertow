The shortcut, made visible

Undertow's control task trains a model to predict pi^k(s0) for a single fixed permutation pi, zero chain-of-thought. It solves k=10 at 100% accuracy while patching finds a causal chain of only about four necessary steps, far short of ten. This page makes the classical shortcut that gap is consistent with concrete: exponentiation by squaring, adapted from integers to permutation composition, proved correct against brute force for every case in tests/test_binary_lifting.py. It is not a claim that the model learned this exact algorithm, only a real, checkable demonstration that a bounded-depth way to solve the task exists at all.

Permutation pi is the project's own control-task permutation (seed 456, m=32), so every number above is real, not illustrative. Powers pi^1, pi^2, pi^4, ... are precomputed once by repeated self-composition (pi^(2i) = pi^i[pi^i]) and reused for any s0 and any k up to the size of the shelf built; the one-time cost of building that shelf is amortized across an entire dataset, exactly like a trained model's weights are. At inference time only the powers whose bit is set in k's binary representation are actually applied, see src/undertow/binary_lifting.py.
